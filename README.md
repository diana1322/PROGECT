# Проект «한집» — сайт строительной компании

## 1. Что это за проект

Это итоговый учебный проект по веб-разработке, в котором объединены материалы двух семестров:

- из первого семестра: HTML, CSS, адаптивная вёрстка, формы, JavaScript, DOM, калькулятор, слайдер, popup;
- из второго семестра: HTTP, работа с PHP, сохранение данных в MySQL/MariaDB, админ-панель, HTTP Basic Auth, базовая защита от уязвимостей.

Тема проекта: **сайт строительной компании** с красивой презентацией домов, выбором проекта, региона и города, расчётом стоимости и отправкой заявки.

---

## 2. Что реализовано в проекте

### Frontend

- красивая главная страница на русском языке;
- корейское название бренда: `한집`;
- hero-блок с большим визуалом;
- каталог из 3 проектов домов;
- онлайн-калькулятор стоимости;
- слайдер-галерея на 8 изображений;
- popup-форма заявки;
- блок-подсказка, какие картинки и под какими именами класть в папку `images`.

### Backend

- подключение к БД учебного сервера через PDO;
- сохранение заявок в MySQL/MariaDB;
- отдельная админ-панель `backend/admin.php`;
- авторизация администратора через HTTP Basic Auth;
- статистика по проектам и регионам;
- редактирование и удаление заявок;
- CSRF-защита для административных действий;
- валидация и безопасная обработка данных.

## 5. Как работает сайт

### 5.1. Каталог проектов

Пользователь видит 3 карточки домов:

- `Urban Mini 84`;
- `Family Comfort 132`;
- `Residence A-186`.

Из карточки можно сразу выбрать проект и перейти к калькулятору.

### 5.2. Калькулятор стоимости

Калькулятор учитывает:

- проект дома;
- регион;
- город;
- пакет строительства;
- дополнительные опции.

### Формула расчёта

```text
Итоговая стоимость = базовая цена проекта × коэффициент региона × коэффициент пакета + сумма доп. опций
```

### 5.3. Popup-форма

Форма собирает:

- ФИО;
- email;
- телефон;
- организацию;
- сообщение;
- согласие на обработку персональных данных.

Форма отправляется через `fetch` в `backend/submit.php`.

### 5.4. Работа с базой данных

При отправке формы данные сохраняются в таблицу `applications` на учебном сервере.

Сохраняются поля:

- ФИО;
- email;
- телефон;
- организация;
- сообщение;
- выбранный проект;
- регион;
- город;
- пакет;
- дополнительные опции;
- итоговая смета;
- IP-адрес;
- дата создания записи.

## 6. Административная панель

Файл админки: `backend/admin.php`.

Что умеет админка:

- открывается по HTTP Basic Auth;
- показывает статистику по проектам;
- показывает статистику по регионам;
- отображает все заявки в таблице;
- позволяет редактировать заявку;
- позволяет удалять заявку.

Для администратора создан отдельный файл:

- `backend/ADMIN_ACCESS.txt` — в нём лежат логин и пароль для входа.

---

## 7. Как подключена БД

В файле `backend/config.php` прописано подключение к учебному серверу по образцу ваших лабораторных:

- `host = localhost`
- `dbname = u82363`
- `user = u82363`
- `password = 3516115`

Подключение выполняется через PDO в `backend/common.php`.

Также в `common.php` реализована функция `ensureSchema()`, которая:

- создаёт таблицу `applications`, если её ещё нет;
- создаёт таблицу `admin_users`, если её ещё нет;
- автоматически добавляет администратора, если запись отсутствует.

Это сделано специально, чтобы проект легче запускался на сервере и не требовал лишних ручных действий.

В проект добавлены меры, чтобы преподавателю было видно, что безопасность учтена:
